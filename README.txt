INTERACTIVE PRODUCT INVENTORY & ANALYTICS DASHBOARD

How to run
1. Extract the ZIP.
2. Open this project's index.html in Chrome (no installation needed).
3. Press F12 > Console to see the JavaScript output from the assignment sheet.
4. Click "Add using prompts" and enter Monitor and 150 to match the provided sample.
5. You can also use the form, search for products, and try tax/discount percentages.
6. Click "Print console report" whenever you need to display the full inventory report.

Requirements demonstrated
- prompt() for name and price, Number() conversion and array of objects
- if/else checks and switch-based Budget / Standard / Premium categories
- for loop, while loop, continue, and early exit when a match is found
- regular and arrow functions with local variables and default parameters
- forEach(), filter(), and map() for the final report
- Simple HTML/CSS interface as a practical extra; console output is retained

Original example data: Laptop ($800), Mouse ($25). Add Monitor ($150) for the sample report total $975.
