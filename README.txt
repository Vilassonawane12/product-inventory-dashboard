# 📦 Interactive Product Inventory & Analytics Dashboard

A responsive and interactive inventory management dashboard developed using **HTML5, CSS3, and JavaScript**. This project demonstrates core JavaScript programming concepts through a practical product inventory application.

## 🚀 Key Features

- **Product Management:** Add products with their names and prices.
- **Inventory Analytics:** View total products, total inventory value, and affordable products.
- **Smart Product Classification:** Automatically categorize products as Budget, Standard, or Premium.
- **Product Search:** Quickly search for available products.
- **Tax & Discount Calculator:** Calculate adjusted product prices using custom tax and discount percentages.
- **Interactive Dashboard:** Clean, user-friendly interface with dynamically updated inventory statistics.
- **Console Reporting:** Generate detailed inventory reports using JavaScript array methods.

## 🛠️ Technologies Used

- HTML5 — Application structure
- CSS3 — Styling and responsive layout
- JavaScript (ES6+) — Application logic and interactivity
- Git & GitHub — Version control and project hosting

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension, or directly in a web browser.
4. Add products using the dashboard form or the **Add using prompts** button.
5. Search products, apply taxes or discounts, and explore the inventory analytics.
6. Open the browser Developer Console (`F12`) to view JavaScript reports.
7. Use **Print console report** to generate a detailed inventory summary.

**No additional installation, backend server, or database is required.**

## 🧠 JavaScript Concepts Demonstrated

- Variables, data types, and type conversion
- Arrays and objects
- Conditional statements (`if/else` and `switch`)
- Loops (`for`, `while`) and control statements
- Regular functions and arrow functions
- Default parameters and local scope
- Array methods (`forEach`, `filter`, `map`)
- DOM manipulation and event handling
